# Every key

Super+/ shows this list inside Slipstream, whenever you forget one. Press Enter there for the tour: fourteen short lessons for anyone new to tiling, each one drawn happening on a miniature of the desktop.

These are the Windows style's keys, which Slipstream starts with. Settings → Keyboard switches to the [Mac style](#mac-style) or the [Omarchy style](#omarchy-style); the list, the tour and the hints on screen then show that style's keys.

| Super+Shift+1–9, Super+Shift+← → | Move the window to a workspace |

The volume, mute, brightness and media keys work as marked, with any player that speaks MPRIS, and stay the desktop's even while a game holds every key. Ctrl+Alt+F1–F12 switch virtual terminals as usual. Keys that input methods, screen readers and games rely on are left alone.

## Mac style

Super is ⌘. Apps keep their own shortcuts, so copy and paste are still Ctrl+C and Ctrl+V. Super is not tapped for the explorer, and Ctrl+Space stays with input methods, as on a Mac. These are the keys that differ from the Windows style; Super+/ lists every one.

| Keys | What they do |
|---|---|
| Super+Space | App explorer |
| Super+Tab, Super+Shift+Tab | Switch windows (Alt+Tab works too) |
| Super+W, Super+Q | Close the window; quit the app, every window of it |
| Super+M, Super+H | Minimise to a stream |
| Super+Alt+M | Hide every window on the workspace, and back |
| Super+Ctrl+F | Fill the tiling area, and back |
| Super+Ctrl+↑ | Bullet time |
| Super+Ctrl+← → | Previous, next workspace |
| Super+Alt+1–9 | Move the window to a workspace |
| Super+Shift+3, Print | Screenshot of the screen |
| Super+Shift+4, Super+Shift+5 | Snip a region or a window |
| Super+Ctrl+Q | Lock |
| Super+Shift+Q | The way out: lock, log out, restart, shut down |
| Super+, | Settings |
| Super+Alt+D, Super+Alt+Shift+D | Dock the window to the bar; bring it back down |

## Inside panels and bullet time

In any panel or card, Esc backs out one level, Tab and the arrows move, Enter presses, and Home, End, PgUp and PgDn jump.

| In bullet time | What they do |
|---|---|
| Arrows, Tab | Choose a window; every window in turn |
| The letter on a window | Jump to it |
| 1–9 | Look at a workspace |
| Enter | Go |
| Shift+1–9, Shift+← → | Send the window to a workspace, or the one beside |
| M, Del | Minimise, close |
| Esc | Back, with nothing changed |

## Run or raise

One key per app: it goes to the app's own workspace and brings its window forward, or starts the app there if it isn't running. Only that workspace is searched, so the same app open somewhere else is left alone. A window the key started goes to the app's workspace even when it appears after you've moved on, and even when it comes from an app already running elsewhere, as a browser's or Ghostty's new windows do. Pressing the key again while the app is still starting waits for it rather than starting a second copy. If the app is minimised, it comes back onto its workspace. With two or more of the app's windows on its workspace, pressing the key again while one has the keyboard goes on to the next, and round to the first again.

The apps are listed in `~/.config/slipstream/settings.toml`, and a change applies as soon as the file is saved:

```toml
[run-or-raise]
raise = "ctrl+super+alt"   # the chord; with Shift added, it sends the focused window instead

[[run-or-raise.app]]
workspace = "Chrome"       # a workspace's name, from [[workspaces.list]]
key = "c"
app = "browser"            # browser, terminal or files: works out the class, and starts that app
command = "chromium --new-window"   # optional with app; run with sh -c

[[run-or-raise.app]]
workspace = "Emacs"
key = "e"
class = "emacs"            # the window's app id (X11: class), any case
title = ""                 # or its exact title, when the class isn't enough
command = "emacsclient --alternate-editor= --create-frame"
```

| Keys | What they do |
|---|---|
| The chord and an app's key | Go to the app's workspace and raise it, or start it there; again, its next window there |
| The chord, Shift and an app's key | Send the focused window to the app's workspace, and follow it |
| The chord and 1–0 | Go to a workspace by its number |
| The chord, Shift and 1–0 | Send the focused window to a workspace by its number |
| The chord and R | Reading mode, as Super+R, unless an app has R |

Ctrl+Super+Alt is the "hyper" chord a keyd layer on one key gives, for example right Alt as `[hyper_mod:C-M-A]`. A run-or-raise key takes over a built-in key on the same chord. Each app appears on the Super+K list under its workspace's name.

A workspace can be pinned to a screen by its connector name, and then always opens there, taking the keyboard with it. The other screens' bars leave it out, and their Super+Tab passes over it. If that screen isn't connected, the workspace opens wherever the keyboard is:

```toml
[[workspaces.list]]
id = 6
screen = "HDMI-A-1"
```

Super+1–9 (and, in the Omarchy style, Super+0) go to the first workspaces in the list, so named run-or-raise workspaces go after those.

An app's workspace can come and go with the app: with `hide-when-empty`, the bar leaves it out while nothing is on it, unless it's on screen.

```toml
[[workspaces.list]]
id = 15
name = "Discord"
hide-when-empty = true
```

The workspace named Reading is shown on the bar as a book.
